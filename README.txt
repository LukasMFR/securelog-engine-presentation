SECURELOG ENGINE · PRÉSENTATION HTML

Présentation de soutenance du projet Python ING3 à l’ECE Paris.
Lukas MAUFFRÉ · Sacha BEHLOULI-DROLLÉE · Jeanne TONDA

Ouvrez index.html dans un navigateur récent. Le diaporama et le rejeu
fonctionnent hors ligne depuis ce fichier. Les diapositives gardent un
format 16:9 fixe. En projection, le canevas remplit un écran 16:9 et
les commandes restent en bas à droite.

Navigation
- Flèches, Espace ou boutons du bas pour avancer et reculer.
- O ouvre le sommaire, F active le plein écran, N affiche les notes et ? ouvre l’aide.
- Sur la diapositive 13, révélez un événement à la fois avec → ou le
  bouton « Révéler un événement ». ← remonte d’un événement. R ou
  « Recommencer » remet la démonstration à zéro.

Le rejeu HTML reprend huit lignes fictives de data/auth.log et les alertes
produites sur ces lignes. Pour exécuter le moteur, lancez python main.py
depuis le dépôt Python. Les notes complètes sont dans notes_orateur.md.
Le rendu, les contrôles et l’adaptation de design-taste-frontend sont
documentés dans VALIDATION.md.
