SECURELOG ENGINE — PRÉSENTATION HTML (20 SLIDES)

1. Ouvrez index.html avec Chrome, Safari, Firefox ou Edge.
2. Utilisez les flèches ← → ou les boutons en bas à droite.
3. O : sommaire ; F : plein écran ; N : notes orateur ; ? : aide ; Esc : fermer.
4. Sur la slide « La démonstration », cliquez « Ligne suivante » : l’animation rejoue une sélection des événements fictifs du dépôt. Cette animation HTML ne lance pas Python.
5. Le document est autonome : aucun serveur, installation, compte ni accès Internet nécessaires.
6. L’impression du document peut également servir de support papier / PDF si nécessaire.

SOURCES : archive du projet fournie par le groupe ; énoncé Markdown ; rapport Jupyter.
Les résultats, mesures mémoire et noms d’étudiants ont été repris des fichiers.
Les défis et axes d’amélioration sont distingués des fonctionnalités déjà réalisées.

DESIGN : direction artistique inspirée des principes de Taste Skill (Leonxlnx/taste-skill, MIT), adaptés à un diaporama HTML hors ligne : hiérarchie typographique, palette unique, un écran par slide, visuels du produit, micro-interactions, transitions et vérification navigateur. L’installation via l’outil n’a pas pu être exécutée dans l’environnement isolé (accès réseau à GitHub indisponible) ; les instructions officielles ont été lues depuis le dépôt et appliquées manuellement.

Pour installer le skill original sur votre ordinateur (facultatif pour la présentation) :
  npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
