03 / MODE D’EXÉCUTION

Deux façons de lancer le moteur

Le moteur peut traiter des fichiers existants ou un flux de texte transmis au terminal.

A / PONCTUEL

Analyser des fichiers

La commande lit les logs fournis, écrit ses résultats, puis se termine.

python main.py
SE TERMINE APRÈS L’ANALYSE
B / FLUX
≋

Suivre une entrée standard

Avec --stream-alerts, chaque alerte sort dès sa détection. La lecture continue tant que le flux reste ouvert.

cat data/*.log | python main.py --stream-alerts -
ACTIF TANT QUE LE FLUX RESTE OUVERT
Le projet ne collecte pas automatiquement les journaux d’un réseau et n’installe aucun service permanent.
Précision essentielle : la commande par défaut fait une analyse finie ; en entrée standard, le programme peut rester actif et émettre les alertes au fil de l’eau. Il n’y a pas de démon ni de serveur H24. Ne pas confondre traitement d’un flux et collecte automatique.

Différence symétrique

IP communes observées : 203.0.113.66 et 198.51.100.24 · blacklist stockée en frozenset immuable.
La blacklist comporte trois IP dont deux apparaissent dans les logs valides. On obtient donc 4 IP actives non blacklistées, 2 présentes dans les deux ensembles et 1 blacklistée non observée. Le moteur calcule les quatre opérations demandées.

whileDécide quand vérifier

breakInterrompt sur un succès

Les exemples admin, root et bob sont ceux des fichiers fournis. Un succès annule immédiatement la série du couple. Le code utilise délibérément while, for, break, continue et else pour respecter le cahier des charges.

18 / PROBLÈMES TECHNIQUES TRAITÉS

Les cas limites traités par le moteur

01

Entrées mal formées

IP incorrecte, JSON tronqué, encodage invalide.

→ Rejet contrôlé, message localisé, option --strict
02

Mémoire maîtrisée

Ne pas charger les fichiers entiers.

→ yield, itérateurs et agrégation progressive
03

Séries de connexions

Un succès doit interrompre les échecs.

→ Historique séparé par couple IP / utilisateur
04

Écriture des résultats

Une erreur en cours de publication ne doit pas effacer les sorties précédentes.

→ Dossier temporaire, sauvegarde et restauration tentée
Il s’agit des difficultés techniques que le projet gère réellement, telles que le montrent le code et les tests. Il ne faut pas les présenter comme des anecdotes personnelles dont nous n’avons pas de preuve.
